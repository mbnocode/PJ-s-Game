# PJ's Game

Nature vs. Robots: a tower defense game PJ designed. Robots roll out of the factory and march toward the grand tree; animal towers stop them.

## Play
- Online: the Vercel link for this project.
- On a computer: double-click `pjs-game.html`.

## Change the game
All the numbers live in **`settings.js`**: tower damage and prices, robot health and speed, the waves, difficulty, the paths, and where the trees, mushrooms and tall grass go. Change a number, save, and reload the game.
