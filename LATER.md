# Ideas for later

Ideas we like but haven't built yet.

- **Gems mode**: the Base holds gems, Robots try to carry them back to their land, and you can win a gem back by destroying the Robot carrying it.
- **More Mythic Towers**: the Pegasus is the first Super Tower. Others from PJ's list: the Golden Fleece and a Cyclops. (The earlier idea of collecting 5 rare parts turned into Golden Acorns and the Upgrades page.)
- **Towers that can be damaged**: skipped because it would make the game really complicated.
- **More levels and more towers**: the game is built so these are easy to add.
- **Saves that follow you between devices**: right now each browser keeps its own save slots.
