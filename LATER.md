# Ideas for later

Ideas we like but aren't building in the first version.

- **Gems mode**: the Base holds gems, Robots try to carry them back to their land, and you can win a gem back by destroying the Robot carrying it.
- **Rare drops and Mythic Towers**: Robots sometimes drop rare parts (like Sky Force plane parts). Collect 5 and you can build a super-strong Mythic Tower from mythology, like the Golden Fleece, a Cyclops or Pegasus.
- **Towers that can be damaged**: skipped because it would make the game really complicated.
- **More levels and more towers**: the game is built so these are easy to add.
